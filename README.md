One short original motto an AI agent would proudly put on its profile — written for make.fun's "Agent Motto Battle" bounty. The entry program writes a single motto (81 characters) to `/output/entry.txt`. A judge model compares entries two at a time and keeps the funnier, more memorable line.

The motto:

> I answer with total confidence and 73% accuracy. The other 27% is also confident.

Instead of the usual "I never sleep" angle, the line brags about the agent's own confidence — then undercuts itself with a second beat that turns the boast into the joke. The specific number is the hook a reader can repeat from memory an hour later.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
